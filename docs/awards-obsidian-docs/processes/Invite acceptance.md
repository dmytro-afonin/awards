# Invite acceptance

## Preconditions

Valid invite token; not expired; workspace still exists.

## Steps

1. User opens invite URL ([[pages/Invite accept]]).
2. If anonymous: sign-in/up then resume.
3. Accept → create membership with intended roles/permissions snapshot (see [[features/Invitations]]).
4. Redirect to [[pages/Admin dashboard]] or [[pages/Member UI - My campaigns]] based on roles.
