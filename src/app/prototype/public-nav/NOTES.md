# Public navigation prototype

**Question:** What should the public site navigation feel like (distinct from admin)?

**Route:** `/prototype/public-nav`

**Controls:** A fixed **magenta bar at the top** of the page (not part of any variant):
1. Three buttons — **A — Arena**, **B — Festival**, **C — Spotlight**
2. Two buttons — **Site pages** vs **Inside a campaign**

## Variants

| ID | Name | Inspiration / structure |
|----|------|-------------------------|
| A | Arena | [The Game Awards](https://thegameawards.com/) — dark cinematic bar, split nav around centered logo, gold accent, horizontal campaign tabs under header |
| B | Festival | Editorial / festival program — light stone palette, horizontal site nav, **left sidebar** for campaign sections when inside a campaign |
| C | Spotlight | Immersive event landing — transparent header on gradient hero, **full-screen menu drawer** for site IA, **sticky pill subnav** for campaign |

## IA covered (mock links)

**Site:** Home, Campaigns, News, FAQ, About

**Campaign:** Campaign, Categories, Nominees, Campaign News, single category (Best Director)

**User menu:** My votes; My campaigns (admin)
